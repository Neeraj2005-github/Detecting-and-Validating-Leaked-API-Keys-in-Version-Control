# Security policy

Report suspected vulnerabilities privately to the repository maintainer. Do not include raw secrets, provider credentials, or sensitive repository content in reports.

SecretGuard expects synthetic local repositories only. Provider validity and rotation calls are out of scope and must remain fail-closed until independently authorized and reviewed.

## Reporting

Use a private maintainer channel. Include no raw findings, credentials, tokens, private URLs, or repository data. Mask values and use fake `FAKE/EXAMPLE` markers in reports.
