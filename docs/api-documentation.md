# API Documentation

The authoritative runtime schema is generated by FastAPI at
`http://localhost:8000/openapi.json` and rendered at `/docs`. The checked-in
[`api-openapi.json`](../api-openapi.json) is a historical snapshot and may not
contain newer CP1 routes.

## Health

`GET /health` checks the configured database and returns:

```json
{"status":"ok","db":"ok"}
```

## CP1 routes

### `POST /api/cp1/scan`

Request:

```json
{
  "repo_url": null,
  "synthetic_fixture": true,
  "use_ai_filter": true
}
```

The response contains `findings`, `suppressed_findings`,
`resolved_findings`, `summary`, and `ndcg`.

### `POST /api/cp1/rotate/{finding_id}`

Accepts optional `{ "force_failure": false }` and returns state transitions,
`mttr_ms`, sandbox name, and (on success) `status: "ROTATED_SAFE"`.

### `GET /api/cp1/overview`

Returns contract, dependency, benchmark, evaluation, SHAP, rotation, and
public-summary evidence used by the workbench.

### `POST /api/cp1/benchmark/run`

Runs the four-way synthetic benchmark and persists its result under
`artifacts/`.

## Compatibility routes

- `POST /api/scan` accepts the CP1 scan request shape.
- `POST /api/rotate` accepts `{ "finding_id": "...", "force_failure": false }`.

## Repository/storage routes

The original API also exposes `/scan`, `/findings`, `/repositories`,
`/scans`, `/metrics`, historical findings, commit details, and blob routes.
These are backed by SQLAlchemy models in
[`src/shd/walker_db.py`](../src/shd/walker_db.py).
