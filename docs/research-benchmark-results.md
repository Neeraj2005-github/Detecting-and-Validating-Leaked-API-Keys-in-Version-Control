# Research benchmark results

## Reproducible environment

- Gitleaks: `8.18.4`
- detect-secrets: `1.5.0`
- Fixture: git fast-import
- Hardware: Intel 12th Gen i5-1235U, 16,831,815,680 RAM bytes, Windows 11 Home

## Report files

- `artifacts/research_benchmark_100_1000.json`
- `artifacts/research_benchmark_10000_partial.json`

The JSON reports contain median, min, max, bootstrap 95% CI, peak RSS,
CPU seconds, and wall seconds for the 100/1,000 five-run measurements and
the 10,000 single-run partial measurement.
